# student-management-python
A simple Python program for managing student names and scores, calculating the average score, and finding the top student

Features:
Add student names and scores
Store student information using dictionaries and lists
Calculate the average score
Sort students by score
Find and display the top student
Technologies Used
Python

How It Works:
The program asks the user to enter the student's name and score.
The user can enter multiple students. When the user enters exit as the name, the program stops receiving new students.
After that, the program calculates the average score and finds the student with the highest score.

How to Run:
Run the following command in the terminal:
python student_management.py
Then enter the students' names and scores when prompted.

Example
enter your name(Whenever it's finished, write the exit): Ali
enter your score: 18
The student's name was successfully registered

enter your name(Whenever it's finished, write the exit): Sara
enter your score: 20
The student's name was successfully registered

enter your name(Whenever it's finished, write the exit): exit

Top Student is: Sara
with a score of: 20.0
